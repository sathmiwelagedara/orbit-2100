# ORBIT 2100 — Cre8X 3.0 Oracle Challenge

A mobile-first React/Vite prototype for the Transportation 2100 challenge.

## Run locally

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite.

## Build for deployment

```bash
npm run build
```

The production files are created in `dist/`.

## Deploy to Vercel

- Push this folder to GitHub.
- Import the repository into Vercel.
- Framework preset: Vite.
- Build command: `npm run build`
- Output directory: `dist`

No backend or database is required for this prototype.

## Main flow

Home → Find Journey → Journey Details → Start Journey → Live Tracking

## Important before submission

- Test on mobile width (390 × 844 is a good reference).
- Check every button.
- Take mobile screenshots of all 3 mandatory screens.
- Put the final Vercel URL in the 6-page report.
